# The File

## Description

A folder tied with tape: a German police report of August 1943, typed in German with a Polish translation, stamped with a black eagle and a swastika; and behind it a single sheet of Polish security-service paper, dated February 1945, signed *H. Kowal*.

## Function

It can destroy two people at once: the priest, by publishing his confession as an accusation, and the official, by proving that a Party functionary denounced a Home Army commander to the secret police.

## History

The German report was captured in 1944 and kept; the 1945 report was created by Rydel and signed by Halina to save Janusz and was used to kill Wiktor Berezowski. Rydel has kept both for thirteen years and uses them in December 1958.

## Current State

Rydel declines to open it. The German half is printed anyway, and the priest has already said the same thing aloud in his own church, which takes the weapon out of it. The Polish half stays in the drawer.
